## 🚀 How to Run

### Method 1: Standalone `.exe` (Easiest)
1. Navigate to the `desktop-translator/dist/` folder.
2. Double-click **`ChatTranslatorAI.exe`**.
3. It will launch quietly in your **Windows System Tray** (near the clock).

### Method 2: One-Click Runner
Double-click **`run_translator.bat`** or **`start_silent.vbs`** (for completely silent background mode).

## ⚙️ How to Start Automatically with Windows (Auto-Startup)
1. Press `Win + R` on your keyboard.
2. Type `shell:startup` and press **Enter**.
3. Right-click `ChatTranslatorAI.exe` (or `start_silent.vbs`), click **Create shortcut**, and paste the shortcut into the Startup folder.
4. Now, every time you turn on your PC, Chat Translator AI will be ready to assist you automatically!
